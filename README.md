# DriveOptima - Kalkulator TCO Nowego Samochodu

Projekt z przedmiotu Inżynieria Oprogramowania.
Aplikacja wylicza optymalny rodzaj napędu (Benzyna, Diesel, LPG, Hybryda, Elektryk) 
w zadanym horyzoncie czasowym w oparciu o profil kierowcy, budżet i realne zużycie energii.

## Stos technologiczny
- **Backend:** Python 3.11+, FastAPI, SQLAlchemy, SQLite
- **Frontend:** React, Vite, Tailwind CSS, Recharts
- **Architektura:** REST API, Model Klient-Serwer
